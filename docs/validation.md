## 可复现检查

```sh
npm ci
npx playwright install chromium
npm test
npm run test:openapi:browser
npm run test:browser
python3 scripts/package_release.py
```

上述命令是验收入口，结果应以实际运行的输出为准；GitHub Actions 当前保留为未启用的模板，本页不把尚未运行的检查记为通过。

| 检查范围 | 验证方式 | 不能由此推出 |
|---|---|---|
| 目录与正文 | 合成普通链接、query、hash、同网址多章、懒加载树、歧义和重复正文 | 任意真实手册目录一定完整 |
| 1200 章续跑 | 队列中断、保存、重建任务并处理剩余项；核对原有内容 | 任意断电、浏览器清理或磁盘故障都不会丢失数据 |
| 三分钟重试 | 可控时钟验证间隔、状态持久化、用户暂停、任务切换、不重复启动；注入网络、登录和加载异常 | 浏览器休眠时仍能严格按墙钟执行，或能自动登录 |
| 导航识别 | 使用不同名称和结构的合成菜单；排除表单、配置提交和危险操作；验证试运行与停止 | 任意菜单实现都可自动识别，或点击会延长设备会话 |
| 导出 | 保存文字、代码、表格、图片；浏览器打开下载的 HTML 并检查离线资源 | 未下载或无法访问的图片也会自动出现 |
| OpenAPI | JSON/YAML、内部引用、循环引用、外部引用缺失、严格扩展 CSP | 外部引用已被补齐，或所描述接口已经执行 |

浏览器集成测试会在 `docs/` 写入本次结果与截图，默认不纳入版本控制。发行包由明确的运行文件清单生成，并核对扩展与 Skill 内资产一致性。公开仓库只包含程序、合成测试和产品说明，不包含设备原始页面、私有诊断、个人路径或历史安装副本。

当前机制的实际边界见 [功能状态](function-status.md)。
